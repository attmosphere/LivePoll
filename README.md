# LivePoll 
A simple polling application built with FastAPI, SQLite, HTML, CSS and JavaScript.

> 🚧 This project is currently under development.

## Features ✅

- Create polls
- Join polls using an ID number
- Vote on poll options
- API error handling

## Tech Stack ⚙️

- Python 
- FastAPI 
- SQLite 
- HTML 
- CSS 
- JavaScript
